🎵 MediaConvert — Инструкция по запуску

Веб-приложение для конвертации аудио и видео через FFmpeg. Проект, НАТК им. Б.С. Галущака, Мандронов Егор.

📋 Что нужно установить

1 Node.js — скачать на nodejs.org (версия LTS, 18+)
После установки проверить в терминале: node -v
2 FFmpeg — скачать на ffmpeg.org или с github.com/BtbN/FFmpeg-Builds

Распакуй архив, например в C:\ffmpeg\

Добавь в PATH путь к папке C:\ffmpeg\bin:
Пуск → «переменные среды» → Переменные среды → Path → Изменить → Создать → вставить путь → ОК

Проверить: ffmpeg -version

🚀 Запуск проекта

3 Открой папку mediaconvert в терминале (Shift+ПКМ → «Открыть окно PowerShell здесь»)
4 Установи зависимости (только один раз): 
npm install
5 Запусти сервер: 
npm start
6 Открой в браузере: http://localhost:3000
Сайт должен открыться и работать!

📁 Структура проекта

mediaconvert/
├── server.js — главный сервер (HTTP + WebSocket)
├── package.json — список зависимостей
├── routes/
│ └── convert.js — маршруты API
├── controllers/
│ └── convertController.js — конвертация через FFmpeg
├── public/
│ └── index.html — весь фронтенд сайта
├── uploads/ — сюда попадают загруженные файлы
└── converted/ — сюда сохраняются результаты

⚠️ Частые проблемы

«ffmpeg is not recognized» — FFmpeg не добавлен в PATH. Перезапусти терминал после добавления.
«Cannot find module» — не выполнен npm install. Запусти его.
Порт 3000 занят — измени порт в server.js последняя строка: const PORT = 3001
